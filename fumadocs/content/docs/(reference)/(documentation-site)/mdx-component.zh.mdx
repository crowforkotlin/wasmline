## 步骤条

<Steps>
  <Step>
    ### 第一步：安装依赖

    ```bash
    pnpm install
    ```
  </Step>
  <Step>
    ### 第二步：启动开发服务器

    ```bash
    pnpm dev
    ```
  </Step>
  <Step>
    ### 第三步：构建网站

    ```bash
    pnpm build
    ```
  </Step>
</Steps>
