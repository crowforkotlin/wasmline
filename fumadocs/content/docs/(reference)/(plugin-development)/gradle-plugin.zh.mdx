# Gradle 插件

`crow.wasmline` 插件会为声明 `wasmWasi` 目标的 Kotlin Multiplatform 模块注册
构建任务。它与 CLI 使用相同的 AOT catalog、compiler resolver、签名代码和
package 写入代码。

## 签名与宿主信任公钥

`manifest.privateKeyFile` 是 package 所有者持有的 Ed25519 私钥。它只由
assemble task 读取来签名 `manifest.wlm`，不会生成到宿主应用中；应由 CI 密钥或
未纳入版本控制的文件提供。

宿主的职责相反：通过 `trust` 配置它信任的公钥。Kotlin Multiplatform 项目默认会在
`commonMain` 生成 `crow.wasmline.generated.WasmlineHostTrust`；Kotlin JVM 项目则在
`main` 生成。该对象实现 `WasmlineTrustedKeys`，业务代码不再保存公钥 Hex 或构造
key set。

```kotlin
wasmline {
    manifest {
        privateKeyFile = file("keys/package-2026.private")
        publicKeyId = "package-2026"
    }
    trust {
        publicKey(
            algorithm = "Ed25519",
            keyId = "package-2026",
            publicKeyHex = "5a778289bee0c57b05a1c48c8ef312da6ce8e4e4f13fc1a2e8e5aa4cde7ae0db",
        )
        // 也可以使用包含相同 Hex 公钥的 UTF-8 文件。
        // publicKeyFile(file("keys/package-2026.public"), keyId = "package-2026")
    }
}
```

加载签名 package 时使用生成对象：

```kotlin
import crow.wasmline.generated.WasmlineHostTrust
import crow.wasmline.loader.WasmlineLoadOptions

val options = WasmlineLoadOptions(trustedKeys = WasmlineHostTrust)
```

`WasmlineLoadOptions` 仍显式传入，以便同一应用能为不同加载操作使用不同信任集合。
默认值不适合宿主项目时，可设置 `trust.sourceSet`、`trust.kotlinPackage`、
`trust.objectName` 或 `trust.generatedSourcesDirectory`。为不同的 `keyId` 声明多个
`publicKey` 或 `publicKeyFile`，即可支持密钥轮换。使用非空 `keyId` 时，package
所有者必须在 `manifest.publicKeyId` 中设置同一个值，Loader 才能选择对应的公钥。
未标识的宿主公钥仍会作为兼容性回退；只有一个未标识公钥时，两侧都应保持未设置。

私有签名密钥仅通过 `manifest.privateKeyFile` 配置。插件刻意不支持在 DSL 中直接填写
私钥字符串，避免私钥进入源码、build scan 或 Gradle 状态；公钥 Hex 不敏感，因此可直接配置。

## AOT Profile 选择

Native AOT 构建会编译 `aotCompatibility` 配置的本地 catalog generation。省略该
block、留空或只配置 `suppressCompatibilityWarning` 都会选择包含当前引入的
Wasmline 构建工具版本的那个 generation；第一次 `generations` 调用会替换这一隐式
current 默认值，之后的调用把各自的策略并入并集。选择与产物 target 相互独立：
`targets` 决定写入哪些文件，配置的 generation 决定编译哪些 AOT profile。

```kotlin
import crow.wasmline.gradle.WasmtimeTarget
import crow.wasmline.plugin.core.aot.AotGenerations

wasmline {
    manifest {
        pluginId = "com.example.plugin"
        version = "1.0.0"
        buildTimestamp = 0L
        privateKeyFile = file("keys/ed25519_private.key")
    }
    wasmtime {
        aotCompatibility {
            generations(AotGenerations.Current)
        }
        targets = listOf(
            WasmtimeTarget.PULLEY_64,
            WasmtimeTarget.X86_64_LINUX,
        )
        autoDownload.set(true)
    }
}
```

命名策略可以选择单个 generation、类型化窗口或具体版本：

```kotlin
import crow.wasmline.plugin.core.aot.AotGenerations

wasmline {
    wasmtime {
        aotCompatibility {
            generations(AotGenerations.Current(before = 1))
            generations(AotGenerations.Latest)
            generations(AotGenerations.Earliest(after = 1))
            generations(AotGenerations.All)
            generations("1.0.0")
            generations(AotGenerations.Versions(min = "1.0.0", max = "1.0.1"))
            generations(versions = listOf("1.0.0", "1.0.1"))
            generations(min = "1.0.0", max = "1.0.1")
            suppressCompatibilityWarning.set(false)
        }
    }
}
```

| 调用 | 选择内容 |
|---|---|
| `generations(AotGenerations.Current)` | 包含当前引入的构建工具版本所在的 generation |
| `generations(AotGenerations.Current(before = 1, after = 1))` | 锚点 generation 加上更早和更晚各一个 AOT generation；两者都必须存在于本地 |
| `generations(AotGenerations.Latest)` / `Latest(before = 1)` | 本地最新 generation，可选地带上更早的相邻 generation |
| `generations(AotGenerations.Earliest(after = 1))` | 本地最早 generation 加一个更晚的相邻 generation |
| `generations(AotGenerations.All)` | 本地 catalog 中保留的全部 generation |
| `generations("1.0.0")` | 包含该具体稳定 Wasmline 版本的 generation |
| `generations(AotGenerations.Versions(...))` | 直接以类型化方式表达相同的点、集合或闭区间选择 |
| `generations(versions = listOf(...))` | 包含这些具体版本的 generation；集合不能为空 |
| `generations(min = "1.0.0", max = "1.0.1")` | 与具体版本闭区间相交的全部 generation |
| 省略 `aotCompatibility` | 当前 generation |

省略 block、留空或只配置警告开关时，选择的是当前 generation。`All` 需要显式选择，
可能编译本地保留的全部 generation，代价可能很高。`Current`、`Latest` 与 `Earliest`
都以 packaged catalog 为基准：`Latest` 是本地保留的最新 generation，`Current` 通过
packaged 构建工具发行版本解析，因此在没有更新 generation 保留时两者指向同一结果。
未来的 generation 无法被旧构建工具远程发现，所以本地 catalog 没有后继时
`Current(after = 1)` 会失败。窗口计数是额外的相邻数量——锚点 generation 始终包含
在内——而且计数的是 AOT generation，不是 Maven 发行版本或 backend profile 变化。
请求的相邻 generation 在本地不存在时会失败，不会被裁剪。

一旦显式调用替换了默认值，后续调用只会并入并集，而不是在当前默认值上追加。版本
重载接受的字符串始终是具体 `x.y.z` 版本：不存在符号版本字符串，也没有
`from`/`through` 重载，更不存在可能把两个版本静默解读为区间的 vararg 形式。每个
具体版本都必须位于 catalog 的
`minimumSupportedWasmlineVersion`..`currentWasmlineVersion` 支持范围内；区间倒置、
越界或其他非法选择会被直接拒绝，不会裁剪为相交部分。generation、请求的 backend 与
复用的 backend profile 都会去重并确定性排序，因此同一 generation 内的多个版本只编译
一次。这些输入是用于选择 catalog generation 的 Wasmline 版本，绝不是 Wasmtime
distribution 版本或 profile 摘要。

在声明了 WASI assemble graph 的项目中，被拒绝的选择会在 Gradle 配置该 graph 阶段
失败，并以 `[WLAOT100]` 报告；AOT 构建与检查 task action 仍会校验各自已求值的
输入。无论走哪条路径，校验都会在下载 compiler asset 或签名 package 之前完成。
仓库根目录的 `aot-compatibility.json` 是唯一人工维护的 AOT catalog。修改后执行
`./scripts/wasmline aot sync`；该命令会校验条目并生成构建工具使用的 packaged
lock。generation 编号只用于排列 catalog 条目，Native 加载仍按已链接 engine
报告的 backend-specific profile ID 匹配。

每次 assemble 成功后，`wasmlineCheckAotCompatibility` 会将本地选择与最新稳定
catalog 比较，并写入 `build/reports/wasmline/aot-compatibility-check.json`。
检查的网络等待时间上限为五秒，即使没有缺失 generation 也会输出警告。
确认报告后才应设置 `suppressCompatibilityWarning.set(true)`；它只隐藏警告，不会
跳过检查或改变 AOT 文件。

`targets` 决定生成文件。PWASM 使用 `pulley32` 或 `pulley64`，CWASM 使用例如
`x86_64-linux` 的平台 target。iOS 只使用 `pulley64`。Compiler archive 从生成
的 lock 解析，并缓存到 `~/.wasmline/toolchains/wasmtime/compiler-assets/sha256/`。
`autoDownload` 只允许下载 lock 中已有摘要的文件。

## Raw Export ABI

`CORE_WASM + RAW_EXPORT` package 使用 `manifest.rawAbi` 声明数值 ABI。Native
和 Web Loader 都读取签名后的 contract。

```kotlin
import crow.wasmline.RawAbiMetadata
import crow.wasmline.RawExport
import crow.wasmline.RawExportKind
import crow.wasmline.RawFunctionSignature
import crow.wasmline.RawValueType
import crow.wasmline.WasmlineExecutionModel
import crow.wasmline.WasmlineInvocationProtocol

wasmline {
    manifest {
        executionModel = WasmlineExecutionModel.CORE_WASM
        invocationProtocol = WasmlineInvocationProtocol.RAW_EXPORT
        exportName = "add_i32"
        rawAbi = RawAbiMetadata(
            exports = listOf(
                RawExport(
                    name = "add_i32",
                    kind = RawExportKind.FUNCTION,
                    signature = RawFunctionSignature(
                        parameters = listOf(RawValueType.I32, RawValueType.I32),
                        results = listOf(RawValueType.I32),
                    ),
                ),
            ),
        )
    }
}
```

不要在 `contractMetadata` 中写入参数或返回值类型。AOT 任务会先规范化
`rawAbi`，再写入 cache input 和 build record。

## 构建并提供 Package

```bash
./gradlew wasmlineAssembleDebug
./gradlew wasmlineAssembleRelease
./gradlew wasmlineServerDeploy
```

多模块构建需要加入模块路径，例如 `./gradlew :plugin:wasmlineAssembleRelease`。

assemble 任务会为全部选中的 profile 和 target 写入一个签名 manifest。Core Web
`.wasm` 只保存一次，输出目录为：

```text
build/wasmline/output/{pluginId}-{version}/
build/wasmline/dist/{pluginId}-{version}.zip
```

```kotlin
import crow.wasmline.gradle.WasmlineBuildVariant

wasmline {
    server {
        host = "0.0.0.0"
        port = 8080
        deployVariant = WasmlineBuildVariant.RELEASE
    }
}
```

`deployVariant` 默认为 `DEBUG`。Server 会提供所选 package 的文件，直到任务停止。

## 注册任务

| 任务 | 用途 |
|---|---|
| `wasmlineAotBuildDebug` | 为配置的 target 构建 Debug AOT profile |
| `wasmlineAotBuildRelease` | 为配置的 target 构建 Release AOT profile |
| `wasmlineCheckAotCompatibility` | 将本地 AOT profile 与最新 catalog 比较 |
| `wasmlineAssembleDebug` | 签名 Debug manifest 并打包文件 |
| `wasmlineAssembleRelease` | 签名 Release manifest 并打包文件 |
| `wasmlineServerDeploy` | 构建并提供 package 目录 |
| `generateWasmlineManifestKeyPairEd25519` | 生成 Ed25519 manifest 密钥对 |
| `wasmlineDownloadComponentTools` | 下载锁定的 `wit-bindgen`、`wasm-tools` 和 WASI adapter |
| `wasmlineComponentizeDebug` | 创建或校验 Debug Component 输入 |
| `wasmlineComponentizeRelease` | 创建或校验 Release Component 输入 |
| `wasmlineGenerateWitBindings` | 未提供 Component 输入时生成 guest binding |
| `wasmlineGenerateHostWitBindings` | 启用 host binding 时生成 host facade |
| `wasmlineGenerateTrustedKeys` | 生成已配置的宿主信任公钥对象 |

Raw Component Wasm 是构建输入，不作为浏览器 artifact 发布。

## 构建替换与可复现性

签名前，Gradle 会构建已配置的 profile 和 target 所选择的每个 AOT artifact。编译、摘要校验、签名或 ZIP 替换失败时，上一
个 package 目录和 ZIP 保持不变。需要可复现字节时，设置
`manifest.buildTimestamp`，通常取自 `SOURCE_DATE_EPOCH`。
