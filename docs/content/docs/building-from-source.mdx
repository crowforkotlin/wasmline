# Building from Source

This page is for developers who want to build the Wasmline framework itself — for example, to fork the repository, modify the runtime or compiler plugin, and submit a pull request. If you only want to **use** Wasmline in your own project, see [Installation](/en/docs/installation).

## System Requirements

| Component | Required Version | Scope |
|---|---|---|
| JDK / JBR | **21** ([JBR 21](https://github.com/JetBrains/JetBrainsRuntime/releases) mandatory for Compose Desktop) | All Gradle operations |
| Kotlin | **2.3.0-RC2** minimum | Wasm GC, function references, exception-handling proposals |
| Android Studio | **LTS** | AGP 9.3.0 compatibility |
| Zig | **0.15.1** | `wasmline-core` JNI shared library compilation |
| Bash / Python 3.9+ / Node.js 18+ | Any one | Platform runtime asset initialization |

The Kotlin/WasmWasi compiler backend must provide complete implementations of the following WebAssembly proposals:

| Proposal | Requirement | Rationale |
|---|---|---|
| GC (garbage collection) | Mandatory | Kotlin managed-object allocation within Wasm linear memory |
| Function References | Mandatory | Interface vtable dispatch and closure representation |
| Exception Handling | Mandatory | Kotlin exception propagation across the Wasm execution boundary |
| Tail Call Optimization | Recommended | Stack overflow prevention in deep recursive call chains |

## Environment Variables

The following environment variables must be configured before building:

```bash
# Android SDK path (required for Gradle Android builds)
export ANDROID_HOME="/home/<user>/Android/Sdk"

# Android NDK path (required for Android native library builds)
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/30.0.15729638"

# MinGW-w64 toolchain path (required for Zig Windows cross-compilation)
export MINGW_PATH="/usr/x86_64-w64-mingw32"

# macOS/Homebrew: use the formula root; build.zig resolves toolchain-x86_64/
# automatically. The brew --prefix path remains valid across formula upgrades.
# export MINGW_PATH="$(brew --prefix mingw-w64)"
```

| Variable | Purpose |
|---|---|
| `ANDROID_HOME` | Locates the Android SDK for Gradle builds |
| `ANDROID_NDK_HOME` | Locates the NDK toolchain for `build-native-assets.sh` Android ABI builds |
| `MINGW_PATH` | Locates the MinGW toolchain root for `build.zig` Windows cross-compilation |

<Callout type="info" title="MINGW_PATH is only needed for Windows cross-compilation">
  If Windows artifacts are not required, `MINGW_PATH` can be omitted. `build-native-assets.sh` skips failed targets and continues building the remaining platforms.
</Callout>

## Environment Preflight

Gradle must not be invoked prior to confirming the active JVM environment. Execute the repository preflight check before each build session:

```bash
bash ./scripts/doctor.sh
```

The script verifies JBR 21 availability, reports desktop Zig/JNI-native status, and reports WARNINGs for missing wasmtime platform/architecture assets under `build/platforms/`.

<Callout type="info" title="local.properties">
  When building or running project commands manually, a `local.properties` file is required in the project root. Open the project in Android Studio and it will generate the file automatically. Ensure this file exists before invoking any Gradle commands outside the IDE.
</Callout>

## Platform Runtime Asset Initialization

Asset initialization is required only for native target builds (Android, iOS, Desktop). Web-only builds do not require wasmtime min C-API assets.

wasmtime min C-API headers and pre-built libraries must be present under `build/platforms/` before native target compilation proceeds. Execute one of the following equivalent scripts:

```bash
sh ./scripts/init-wasmtime.sh          # Bash — requires curl and tar/unzip
python3 ./scripts/init-wasmtime.py     # Python 3.9+ — no third-party dependencies
node ./scripts/init-wasmtime.mjs       # Node.js 18+ — no third-party dependencies
```

All three scripts support interactive platform/architecture selection, configurable download concurrency, and an optional HTTP proxy as the first positional argument (e.g., `127.0.0.1:7890`).

## Native Library Build

Native library compilation is handled by `build-native-assets.sh`. This script builds all target platform artifacts for Android (CMake + NDK) and JVM Desktop (Zig), then deploys them to the corresponding engine module's `jniLibs` / `resources` directory.

```bash
# Builds both pulley and cranelift variants by default
bash scripts/build-native-assets.sh

# Build a specific variant only
bash scripts/build-native-assets.sh pulley
bash scripts/build-native-assets.sh cranelift
```

Prerequisites:
- `init-wasmtime.sh` has been executed to download platform runtime assets
- `ANDROID_NDK_HOME` is set (Android targets)
- Zig 0.15.1 is installed (JVM Desktop targets)
- `MINGW_PATH` is set (Windows cross-compilation, optional)

### Manual Zig Build (Desktop Only)

To build the JVM Desktop JNI shared library in isolation, invoke Zig directly:

```bash
cd wasmline-multiplatform/wasmline

zig build --release=small -p src/jvmMain/resources   # Release (size-optimized)
zig build -p src/jvmMain/resources                    # Debug
```

<Callout type="warn" title="Do not commit Zig intermediates">
  Files under `zig-out/` are intermediate Zig build artifacts and must not be committed. The `-p src/jvmMain/resources` flag is required to redirect JNI library installation to the correct classpath resource directory.
</Callout>

## Gradle Build Reference

All operations are executed from `wasmline-multiplatform/`:

```bash
cd wasmline-multiplatform

# Full project build
./gradlew build

# wasmline-loader module tests (manifest parsing, cryptographic verification)
./gradlew :wasmline-loader:jvmTest

# wasmline-cli module tests
./gradlew :wasmline-cli:test

# Kotlin/WasmWasi plugin sample compilation
./gradlew :wasmline-sample:plugin:compileProductionLibraryKotlinWasmWasiOptimize

# IR compiler plugin — regenerate test runners from testData fixtures
./gradlew :wasmline-kotlin-plugin:generateTests

# IR compiler plugin — box test execution
./gradlew :wasmline-kotlin-plugin:test \
  --tests 'crow.wasmline.kotlin.runners.JvmBoxTestGenerated'

# IR compiler plugin — diagnostic validation tests
./gradlew :wasmline-kotlin-plugin:test \
  --tests 'crow.wasmline.kotlin.runners.JvmDiagnosticsTestGenerated'

# Install all modules to the local Maven repository (mavenLocal)
./gradlew publishToMavenLocal
```

## Version Sync

Shared documentation and duplicated config version strings are synchronized from `scripts/versions.json`:

```bash
python3 scripts/sync_versions.py --check
python3 scripts/sync_versions.py --set wasmtime_version=<new-version>
```
