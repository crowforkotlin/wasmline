# wasmline

Wasmline is a Kotlin Multiplatform framework for loading and calling WASI-compliant WebAssembly plugins in Android, iOS, Desktop, and Web applications. Service contracts are declared as Kotlin `interface` types, and the bundled Kotlin IR compiler plugin generates all serialization and dispatch code at compile time.

## Platform Support

| Platform | Architecture | Artifact Support | Loading |
|---|---|---|---|
| Android | v8a, x86_64 | `.cwasm` / `.pwasm` | wasmtime |
| Android | v7a, x86 | `.pwasm` only | wasmtime |
| iOS | arm64 | `.pwasm` | wasmtime |
| macOS | arm64 | `.cwasm` / `.pwasm` | wasmtime |
| Linux | x86_64 | `.cwasm` / `.pwasm` | wasmtime |
| Windows | x86_64 | `.cwasm` / `.pwasm` | wasmtime |
| Web (Kotlin/JS · Kotlin/WasmJS) | Browser JS engine | Raw `.wasm` only | web |

<Callout type="warn" title="Web artifact constraint">
  AOT artifacts generated by the CLI pipeline (`.cwasm`, `.pwasm`) are not valid Web inputs. Web targets accept raw `.wasm` binaries only.
</Callout>
