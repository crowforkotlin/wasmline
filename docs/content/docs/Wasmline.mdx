# WasmLine

WasmLine 是一个跨多平台兼容性解决方案。它以 **Kotlin Multiplatform** 为基础，支持使用**任何编程语言**开发兼容 Wasi 的插件。

**支持平台：** Android, Windows, Ubuntu, MacOS

## 🚀 支持与发现

### 未来计划
- **IOS**: 计划使用 Kotlin Native 进行研究。
- **Web**: 进一步的 WebAssembly 支持。

<Callout type="warn" title="Kotlin/Wasi 运行时警告">
  截至 **2025 年 12 月 4 日**，只有 **Kotlin 2.3.0-RC** 提供了可靠的支持。
  
  其他运行时可能会抛出错误，或无法完全支持最新的 Wasm 特性。
</Callout>

## ⚙️ AOT 编译配置

Android 目标 (`aarch64-linux-android`) 需要配合 AOT 编译以启用垃圾回收 (`gc=y`)。

<Callout type="info">
  Kotlin 需要特定功能支持 (simd, relaxed-simd 等)，以下是经过测试的配置。
</Callout>

```bash title="compile.sh"
wasmtime compile plugin.wasm -o plugin.cwasm \
    --target aarch64-linux-android \
    -W gc=y \
    -W function-references=y \
    -W exceptions=y \
    -W simd=n \
    -W relaxed-simd=n \
    -O static-memory-guard-size=0 \
    -O dynamic-memory-guard-size=0 \
    -O signals-based-traps=n \
    -O opt-level=2 \
    -C cranelift-debug-verifier=no
