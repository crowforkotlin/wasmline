# 安装

在 Gradle 项目中通过 Maven 构件使用 Wasmline。需要构建 Wasmline 仓库本身时，参阅
[从源码编译](/zh/docs/building-from-source)。

## 环境要求

- JBR **21**
- Kotlin **2.3.0-RC2** 或更高版本

<Callout type="warn" title="Kotlin 版本要求">
  最低需要 **Kotlin 2.3.0-RC2** 版本。更低版本可能生成不完整的 Kotlin/WasmWasi 二进制文件，不能
  用于 Wasmline 插件。
</Callout>

## 应用 Gradle 插件

在使用生成的 `link<T>()` 或 `bind(impl)` 调用的编译单元中应用插件：

```kotlin
// build.gradle.kts
plugins {
    id("crow.wasmline") version "1.0.0"
}
```

插件会应用 `wasmline-kotlin-plugin`。未应用时，公开的
`Wasmline.callResult(action, bytes)` API 仍可使用，但 `link<T>()` 和 `bind(impl)`
会在运行时抛出 `UnsupportedOperationException`。

## 添加运行时依赖

使用 BOM，让全部 Wasmline 模块使用同一版本。添加 `wasmline-loader` 和一个原生
engine 模块。只有宿主需要下载远程 manifest 或缓存中不存在的产物时，才添加
network 模块。

```kotlin
dependencies {
    implementation(platform("crow.wasmline:wasmline-bom:1.0.0"))
    implementation("crow.wasmline:wasmline-loader")
    implementation("crow.wasmline:wasmline-engine-pulley")

    // 仅在支持的原生目标执行远程加载时需要。
    implementation("crow.wasmline:wasmline-network-ktor")
}
```

| 模块 | 用途 |
|---|---|
| `wasmline` | 运行时 API、服务分发和序列化 SPI |
| `wasmline-loader` | manifest 解析、签名校验、缓存访问和产物选择 |
| `wasmline-network-ktor` | JVM、Android、Apple、Linux 和 Windows Native 的远程加载 |
| `wasmline-network-okhttp` | 使用 OkHttp 的 JVM 和 Android 远程加载 |
| `wasmline-engine-pulley` | 加载匹配的 `.pwasm` |
| `wasmline-engine-cranelift` | 加载匹配的 `.cwasm`，也可加载匹配的 `.pwasm` |

BOM 让 runtime、loader、插件、CLI、插件构建工具和 engine 模块使用同一
Wasmline 版本。不要单独升级 engine 模块。

## Kotlin/Native 宿主

在 Native source set 中添加相同的运行时模块。已发布的 Kotlin Multiplatform
metadata 会为 iOS、macOS、Linux 或 Windows 选择匹配的静态 Wasmtime bridge。

```kotlin
val wasmlineVersion = "1.0.0"

kotlin {
    sourceSets {
        val nativeMain by getting {
            dependencies {
                implementation("crow.wasmline:wasmline:$wasmlineVersion")
                implementation("crow.wasmline:wasmline-loader:$wasmlineVersion")
                implementation("crow.wasmline:wasmline-engine-pulley:$wasmlineVersion")
            }
        }
    }
}
```

`wasmline-engine-pulley` 加载匹配的 `pulley32` 或 `pulley64` `.pwasm`。
`wasmline-engine-cranelift` 先查找 target 和 profile 完全匹配的 `.cwasm`；只有
同时存在匹配的 Pulley profile 时才使用 `.pwasm`。iOS 只使用 `pulley64`
`.pwasm`。

<Callout type="info" title="Network 模块是可选依赖">
  本地 manifest 和本地产物不需要 Ktor 或 OkHttp。Loader 会在使用 network client
  前检查缓存。浏览器加载 raw `.wasm` 使用 `WasmlineWeb.prefetch()`，不使用原生
  network 模块。
</Callout>

## 当前分发方式

Wasmline 当前通过 `mavenLocal()` 分发。在本仓库执行下面命令后，其他本地项目可
引用这些构件：

```bash
cd wasmline-multiplatform
./gradlew publishToMavenLocal
```
