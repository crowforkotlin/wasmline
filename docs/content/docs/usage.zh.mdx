# 使用

本页说明常用服务 API：在共享代码定义契约，在插件实现契约，在宿主加载插件并调用
契约。固定的 Component Model 服务格式参见
[组件服务协议](/zh/docs/component-service)。

## 1. 定义服务契约

在共享源码中声明继承 `WasmlineService` 的 Kotlin `interface`。每个方法对应一个
`<完全限定契约名>#<方法名>` 格式的 action。服务中不能声明同名重载方法。

```kotlin
// shared/src/commonMain/kotlin/com/example/EchoService.kt
import crow.wasmline.WasmlineService

interface EchoService : WasmlineService {
    fun echo(message: String): String
}
```

## 2. 实现插件

插件在 `wasmWasiMain` 入口中绑定实现。Kotlin IR 编译器插件会将 `bind(impl)` 替换为
对生成 bridge 类的调用。

```kotlin
// plugin/src/wasmWasiMain/kotlin/Main.kt
import crow.wasmline.Wasmline
import crow.wasmline.bind

fun main() {
    Wasmline.get().bind(object : EchoService {
        override fun echo(message: String): String = "插件响应：$message"
    })
}
```

## 3. 加载并调用插件

`WasmlineLoader.load()` 返回包含已加载 `Wasmline` 的
`WasmlineLoadResult.Success`，或返回包含 `WasmlineLoadFailure` 的
`WasmlineLoadResult.Failure`。下面示例加载一个签名后的远程 manifest。本地 manifest
路径或本地产物不需要 network client。

```kotlin
import crow.wasmline.WasmlineLoadResult
import crow.wasmline.link
import crow.wasmline.loader.WasmlineLoadOptions
import crow.wasmline.loader.WasmlineLoader
import crow.wasmline.loader.WasmlineTrustedKeySet
import crow.wasmline.network.ktor.KtorNetworkClient

suspend fun callPlugin() {
    val module = when (val result = WasmlineLoader.load(
        source = "https://example.com/plugin/manifest.wlm",
        options = WasmlineLoadOptions(
            networkClient = KtorNetworkClient(),
            trustedKeys = WasmlineTrustedKeySet.Builder()
                .addHex(
                    algorithm = "Ed25519",
                    keyId = "release",
                    publicKeyHex = "5a778289bee0c57b05a1c48c8ef312da6ce8e4e4f13fc1a2e8e5aa4cde7ae0db",
                )
                .build(),
        ),
    )) {
        is WasmlineLoadResult.Success -> result.wasmline
        is WasmlineLoadResult.Failure -> error(result.failure.message)
    }

    try {
        val reply = module.link<EchoService>().echo("ping")
        println(reply)
    } finally {
        module.close()
    }
}
```

Loader 会在选择产物前校验 manifest 签名。远程 package 只请求 manifest 和一个已选择
的产物，不会下载离线 ZIP 或其他平台的文件。

## 加载来源与资源释放

| 来源 | 可用平台 | 要求 |
|---|---|---|
| 本地 manifest | Native 和 Web，前提是存在匹配平台的 variant | 将路径传给 `WasmlineLoader.load()` |
| 远程 manifest URL | Native 和 Web，前提是存在匹配平台的 variant | 提供 trusted key；缓存未命中时提供 network client |
| 本地 `.cwasm` 或 `.pwasm` descriptor | 仅 Native | 声明执行模型、调用协议和匹配的 profile |
| Raw `.wasm` descriptor | 仅 Web Core Wasm | 加载前注册或预取字节 |

每个成功加载的模块都要调用 `Wasmline.close()`。`WasmlineRuntime.shutdown()` 会关闭
全部存活的 Wasmline module 和 session，只应在应用或进程退出时调用。

## 选择调用 API

| 执行模型和协议 | 主要 API | 可用平台 |
|---|---|---|
| `CORE_WASM + WASMLINE_SERVICE` | `link<T>()`、`bind(impl)` 或 `callResult()` | Native 和 Web |
| `CORE_WASM + RAW_EXPORT` | `CoreWasmModule`、`CoreWasmSession` 和 `RawValue` | Native 和 Web |
| `COMPONENT_MODEL + WASMLINE_SERVICE` | `link<T>()` 和 `bind(impl)` | 仅 Native |
| `COMPONENT_MODEL + COMPONENT_EXPORT` | `invokeComponentResult()` | 仅 Native |

文件扩展名不会决定 API。签名后的 manifest 或显式
`WasmlineArtifactDescriptor` 会声明执行模型和调用协议。

## 调用 Raw Export

Raw Export 不使用服务 action 字节。它调用已声明的数值 export，并返回 `RawValue`。
Web API 要求先注册字节，并在实例化前注册全部 import。Web 的 `i64` 在 JavaScript
边界使用 `BigInt`；import 回调必须同步返回。

```kotlin
import crow.wasmline.CoreWasmSessionOptions
import crow.wasmline.RawAbiMetadata
import crow.wasmline.RawExport
import crow.wasmline.RawExportKind
import crow.wasmline.RawFunctionSignature
import crow.wasmline.RawImport
import crow.wasmline.RawImportDeclaration
import crow.wasmline.RawValue
import crow.wasmline.RawValueType
import crow.wasmline.WasmlineArtifactDescriptor
import crow.wasmline.WasmlineArtifactFormat
import crow.wasmline.WasmlineCoreLoadResult
import crow.wasmline.WasmlineExecutionModel
import crow.wasmline.WasmlineInvocationProtocol
import crow.wasmline.WasmlineWeb
import crow.wasmline.invocation.WasmlineCallResult
import crow.wasmline.loader.WasmlineLoader

WasmlineWeb.registerBytes("math.wasm", wasmBytes)
val module = when (val loaded = WasmlineLoader.loadCoreModule(
    WasmlineArtifactDescriptor(
        path = "math.wasm",
        artifactFormat = WasmlineArtifactFormat.RAW_WASM,
        executionModel = WasmlineExecutionModel.CORE_WASM,
        invocationProtocol = WasmlineInvocationProtocol.RAW_EXPORT,
        rawAbi = RawAbiMetadata(
            exports = listOf(
                RawExport(
                    name = "add",
                    kind = RawExportKind.FUNCTION,
                    signature = RawFunctionSignature(
                        parameters = listOf(RawValueType.I32, RawValueType.I32),
                        results = listOf(RawValueType.I32),
                    ),
                ),
            ),
            imports = listOf(
                RawImportDeclaration(
                    module = "env",
                    name = "host_add",
                    signature = RawFunctionSignature(
                        parameters = listOf(RawValueType.I32, RawValueType.I32),
                        results = listOf(RawValueType.I32),
                    ),
                ),
            ),
        ),
    ),
)) {
    is WasmlineCoreLoadResult.Success -> loaded.module
    is WasmlineCoreLoadResult.Failure -> error(loaded.failure.message)
}

val session = module.instantiate(
    CoreWasmSessionOptions(
        imports = listOf(
            RawImport(
                module = "env",
                name = "host_add",
                signature = RawFunctionSignature(
                    parameters = listOf(RawValueType.I32, RawValueType.I32),
                    results = listOf(RawValueType.I32),
                ),
            ) { _, values ->
                val left = (values[0] as RawValue.I32).value
                val right = (values[1] as RawValue.I32).value
                WasmlineCallResult.Success(listOf(RawValue.I32(left + right)))
            },
        ),
    ),
).getOrThrow()

try {
    val values = session.invoke("add", listOf(RawValue.I32(2), RawValue.I32(3))).getOrThrow()
    check(values == listOf(RawValue.I32(5)))
} finally {
    session.close()
    module.close()
}
```

Native Raw Export 使用匹配的 `.cwasm` 或 `.pwasm` descriptor，而不是
`RAW_WASM`。session API、标量值、import 和有边界检查的内存 API 保持一致。

## 处理结果和错误

普通调用错误需要作为数据处理时，使用 `callResult()`、`invokeRawResult()`、
`invokeComponentResult()` 或 Core session 的结果 API。结果只有 `Success(value)` 与
`Failure(failure)` 两种状态。应根据 `failure.code` 分支，不要解析
`failure.message` 文本。

例如，没有绑定 handler 的 action 返回 `ACTION_NOT_BOUND`。
`throwOnFailure()` 只在调用方明确要求异常时才把失败转换为
`WasmlineException`。Core 响应帧字段和产物规则参见 [常见问题](/zh/docs/faq)。
