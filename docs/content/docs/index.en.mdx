## Introduction

Welcome to the **Wasmline** documentation. This project is dedicated to providing a seamless experience for developers working with WebAssembly and Next.js.

### Key Features

- **Blazing Fast**: Powered by Next.js 15 and Turbopack.
- **MDX Support**: Write your docs in Markdown with the power of React components.
- **Search Built-in**: Local search functionality out of the box.
- **Tailwind CSS**: Fully customizable styling.
