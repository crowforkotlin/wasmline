# Gradle 插件

`crow.wasmline` 插件会为声明 `wasmWasi` 目标的 Kotlin Multiplatform 模块注册构件任务。

## 构建与服务

```bash
# 本地验证包
./gradlew wasmlineAssembleDebug

# 发行包
./gradlew wasmlineAssembleRelease

# 构建并提供选定的构件
./gradlew wasmlineServerDeploy
```

构件目录为 `build/wasmline/output/{pluginId}-{version}/`，发行压缩包为 `build/wasmline/dist/{pluginId}-{version}.zip`。

多模块项目需要增加模块路径，例如 `./gradlew :plugin:wasmlineAssembleRelease`。

## 服务配置

```kotlin
import crow.wasmline.gradle.WasmlineBuildVariant

wasmline {
    server {
        host = "0.0.0.0"
        port = 8080
        deployVariant = WasmlineBuildVariant.RELEASE
    }
}
```

`deployVariant` 默认为 `WasmlineBuildVariant.DEBUG`。`wasmlineServerDeploy` 会构建选定的构件，并持续提供其中的文件，直到任务停止。

本页列出插件定义的全部 15 个面向用户的任务。

## 工具链与签名任务

| 任务 | 用途 |
|---|---|
| `checkWasmlineToolchain` | 检查 Core Wasm 打包使用的精简 Wasmtime 工具链 |
| `wasmlineDownloadWasmtime` | 下载精简 Wasmtime 工具链 |
| `wasmlineDownloadWasmtimeCompiler` | 下载 Component AOT 编译使用的完整 Wasmtime CLI |
| `wasmlineDownloadComponentTools` | 下载 `wit-bindgen`、`wasm-tools` 和 WASI Preview 1 adapter |
| `generateWasmlineManifestKeyPairEd25519` | 生成 Ed25519 清单签名密钥对 |
| `generateWasmlineManifestKeyPairEcdsaP256` | 生成 ECDSA P-256 清单签名密钥对 |

## Component 流水线任务

四个 Componentize 和 AOT 任务会随 `wasmWasi` 目标注册，仅在 Component 构建中接入 assemble 任务。未设置 `componentInput` 的 Component 构建会注册 `wasmlineGenerateWitBindings`。`hostBindingsEnabled = true` 时会注册 `wasmlineGenerateHostWitBindings`。直接执行仅用于检查单个流水线阶段。

| 任务 | 用途 |
|---|---|
| `wasmlineGenerateWitBindings` | 根据 WIT 生成 Kotlin guest binding |
| `wasmlineGenerateHostWitBindings` | 启用 host binding 时，根据 WIT 生成 Kotlin host facade |
| `wasmlineComponentizeDebug` | 创建或校验 Debug Component |
| `wasmlineComponentizeRelease` | 创建或校验 Release Component |
| `wasmlineComponentAotDebug` | 将 Debug Component 编译为已配置目标的 CWASM 和 PWASM |
| `wasmlineComponentAotRelease` | 将 Release Component 编译为已配置目标的 CWASM 和 PWASM |

`wasmlineAssembleDebug` 和 `wasmlineAssembleRelease` 会自动执行所需的编译、工具下载、binding 生成、Component 转换、AOT、清单、签名和打包步骤。

缓存与下载配置参见 [Wasmtime 工具链](/zh/docs/wasmtime-download)。
