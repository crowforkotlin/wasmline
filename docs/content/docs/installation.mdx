# Installation

Wasmline is consumed as Maven artifacts in your own Gradle project. If you want to build the framework itself from source or contribute to it, see [Building from Source](/en/docs/building-from-source).

## Requirements

- JDK / JBR **21**
- Kotlin **2.3.0-RC2** or later

<Callout type="warn" title="Kotlin version requirement">
  The minimum required Kotlin version is **2.3.0-RC2**. Below this version, the Kotlin/WasmWasi compiler backend may produce incomplete Wasm binaries, manifesting as plugin load failures or undefined behavior at the `Session.invoke` boundary.

  ![Kotlin/Wasm runtime support matrix](/images/kotlin_support.png)
</Callout>

## Apply the Gradle Plugin

```kotlin
// build.gradle.kts
plugins {
    id("crow.wasmline") version "1.0.0"
}
```

The plugin applies the `wasmline-kotlin-plugin` IR compiler plugin to the current compilation unit, rewriting `link<T>()` and `bind(impl)` call sites at compile time. Without it, those calls throw `UnsupportedOperationException` at runtime.

## Add Dependencies

```kotlin
dependencies {
    // Core loader — manifest parsing, signature verification, module loading
    implementation("crow.wasmline:wasmline-loader:1.0.0")

    // Optional: HTTP client for remote-manifest cache misses
    implementation("crow.wasmline:wasmline-network-ktor:1.0.0")

    // Engine backend — provides the native runtime library per platform variant
    implementation("crow.wasmline:wasmline-engine-pulley:1.0.0")
}
```

| Artifact | Description |
|---|---|
| `crow.wasmline:wasmline` | Core runtime — execution, dispatch, serialization SPI |
| `crow.wasmline:wasmline-loader` | Load options, cache/network SPI, `.wlm` parsing and signature verification |
| `crow.wasmline:wasmline-network-ktor` | Ktor adapter for remote loading (JVM, Android, iOS) |
| `crow.wasmline:wasmline-network-okhttp` | HTTP network client backed by OkHttp 5.x (JVM/Android) |
| `crow.wasmline:wasmline-engine-pulley` | Pulley-only interpreter — `.pwasm` only, all native targets |
| `crow.wasmline:wasmline-engine-cranelift` | Cranelift + Pulley runtime — `.cwasm` first, `.pwasm` fallback |

<Callout type="info" title="Network adapters are optional">
  `wasmline-loader` defines the network, cache, and trust abstractions but does not select an HTTP engine. Local artifacts and local manifests need no network module. For a remote manifest, choose Ktor or OkHttp only when the application must fetch a missing or expired manifest or a missing artifact. A fresh manifest and its selected artifact can be loaded from cache without a network client. Browser raw `.wasm` loading uses `WasmlineWeb.prefetch()` instead of either adapter.
</Callout>

<Callout type="info" title="Distribution status">
  Wasmline is under active development. Artifacts are currently distributed through `mavenLocal()` — run `./gradlew publishToMavenLocal` in `wasmline-multiplatform/` to install them locally. Maven Central publishing is in progress.
</Callout>
