# Usage

This page shows the normal service API: define a contract in shared code,
implement it in a plugin, load the plugin in the host, and call the contract.
For the fixed Component Model service format, see
[Component Service Protocol](/en/docs/component-service).

## 1. Define a Service Contract

Declare a Kotlin `interface` in shared source and extend `WasmlineService`.
Each method becomes an action named
`<fully-qualified-contract-name>#<method-name>`. A service cannot overload a
method name.

```kotlin
// shared/src/commonMain/kotlin/com/example/EchoService.kt
import crow.wasmline.WasmlineService

interface EchoService : WasmlineService {
    fun echo(message: String): String
}
```

## 2. Implement the Plugin

The plugin binds an implementation in its `wasmWasiMain` entry point. The
Kotlin IR compiler plugin replaces `bind(impl)` with a call to the generated
bridge class.

```kotlin
// plugin/src/wasmWasiMain/kotlin/Main.kt
import crow.wasmline.Wasmline
import crow.wasmline.bind

fun main() {
    Wasmline.get().bind(object : EchoService {
        override fun echo(message: String): String = "Plugin response: $message"
    })
}
```

## 3. Load and Call the Plugin

`WasmlineLoader.load()` returns `WasmlineLoadResult.Success` with a loaded
`Wasmline` instance or `WasmlineLoadResult.Failure` containing a
`WasmlineLoadFailure`. The example below loads a signed remote manifest. A
local manifest path or local artifact does not require a network client.

```kotlin
import crow.wasmline.WasmlineLoadResult
import crow.wasmline.link
import crow.wasmline.loader.WasmlineLoadOptions
import crow.wasmline.loader.WasmlineLoader
import crow.wasmline.loader.WasmlineTrustedKeySet
import crow.wasmline.network.ktor.KtorNetworkClient

suspend fun callPlugin() {
    val module = when (val result = WasmlineLoader.load(
        source = "https://example.com/plugin/manifest.wlm",
        options = WasmlineLoadOptions(
            networkClient = KtorNetworkClient(),
            trustedKeys = WasmlineTrustedKeySet.Builder()
                .addHex(
                    algorithm = "Ed25519",
                    keyId = "release",
                    publicKeyHex = "5a778289bee0c57b05a1c48c8ef312da6ce8e4e4f13fc1a2e8e5aa4cde7ae0db",
                )
                .build(),
        ),
    )) {
        is WasmlineLoadResult.Success -> result.wasmline
        is WasmlineLoadResult.Failure -> error(result.failure.message)
    }

    try {
        val reply = module.link<EchoService>().echo("ping")
        println(reply)
    } finally {
        module.close()
    }
}
```

The loader verifies the manifest signature before it selects an artifact. For a
remote package, it fetches the manifest and one selected artifact; it does not
download the offline ZIP or unrelated platform files.

## Load Sources and Ownership

| Source | Accepted by | Requirement |
|---|---|---|
| Local manifest | Native and Web, when its variants match the platform | Supply a path to `WasmlineLoader.load()` |
| Remote manifest URL | Native and Web, when its variants match the platform | Supply trusted keys and a network client for cache misses |
| Local `.cwasm` or `.pwasm` descriptor | Native only | Specify the execution model, invocation protocol, and matching profile |
| Raw `.wasm` descriptor | Web Core Wasm only | Register or prefetch bytes before loading |

Call `Wasmline.close()` for each successfully loaded module. Use
`WasmlineRuntime.shutdown()` only at application or process shutdown because it
closes every live Wasmline module and session.

## Choose an Invocation API

| Execution model and protocol | Main API | Where it runs |
|---|---|---|
| `CORE_WASM + WASMLINE_SERVICE` | `link<T>()`, `bind(impl)`, or `callResult()` | Native and Web |
| `CORE_WASM + RAW_EXPORT` | `CoreWasmModule`, `CoreWasmSession`, and `RawValue` | Native and Web |
| `COMPONENT_MODEL + WASMLINE_SERVICE` | `link<T>()` and `bind(impl)` | Native |
| `COMPONENT_MODEL + COMPONENT_EXPORT` | `invokeComponentResult()` | Native |

The file extension does not choose this API. A signed manifest or explicit
`WasmlineArtifactDescriptor` declares the execution model and invocation
protocol.

## Call a Raw Export

Raw Export does not use service action bytes. It calls declared numeric exports
and returns `RawValue` values. The Web API requires byte registration and all
imports before instantiation. Web `i64` values cross the JavaScript boundary as
`BigInt`; an import callback must return synchronously.

```kotlin
import crow.wasmline.CoreWasmSessionOptions
import crow.wasmline.RawAbiMetadata
import crow.wasmline.RawExport
import crow.wasmline.RawExportKind
import crow.wasmline.RawFunctionSignature
import crow.wasmline.RawImport
import crow.wasmline.RawImportDeclaration
import crow.wasmline.RawValue
import crow.wasmline.RawValueType
import crow.wasmline.WasmlineArtifactDescriptor
import crow.wasmline.WasmlineArtifactFormat
import crow.wasmline.WasmlineCoreLoadResult
import crow.wasmline.WasmlineExecutionModel
import crow.wasmline.WasmlineInvocationProtocol
import crow.wasmline.WasmlineWeb
import crow.wasmline.invocation.WasmlineCallResult
import crow.wasmline.loader.WasmlineLoader

WasmlineWeb.registerBytes("math.wasm", wasmBytes)
val module = when (val loaded = WasmlineLoader.loadCoreModule(
    WasmlineArtifactDescriptor(
        path = "math.wasm",
        artifactFormat = WasmlineArtifactFormat.RAW_WASM,
        executionModel = WasmlineExecutionModel.CORE_WASM,
        invocationProtocol = WasmlineInvocationProtocol.RAW_EXPORT,
        rawAbi = RawAbiMetadata(
            exports = listOf(
                RawExport(
                    name = "add",
                    kind = RawExportKind.FUNCTION,
                    signature = RawFunctionSignature(
                        parameters = listOf(RawValueType.I32, RawValueType.I32),
                        results = listOf(RawValueType.I32),
                    ),
                ),
            ),
            imports = listOf(
                RawImportDeclaration(
                    module = "env",
                    name = "host_add",
                    signature = RawFunctionSignature(
                        parameters = listOf(RawValueType.I32, RawValueType.I32),
                        results = listOf(RawValueType.I32),
                    ),
                ),
            ),
        ),
    ),
)) {
    is WasmlineCoreLoadResult.Success -> loaded.module
    is WasmlineCoreLoadResult.Failure -> error(loaded.failure.message)
}

val session = module.instantiate(
    CoreWasmSessionOptions(
        imports = listOf(
            RawImport(
                module = "env",
                name = "host_add",
                signature = RawFunctionSignature(
                    parameters = listOf(RawValueType.I32, RawValueType.I32),
                    results = listOf(RawValueType.I32),
                ),
            ) { _, values ->
                val left = (values[0] as RawValue.I32).value
                val right = (values[1] as RawValue.I32).value
                WasmlineCallResult.Success(listOf(RawValue.I32(left + right)))
            },
        ),
    ),
).getOrThrow()

try {
    val values = session.invoke("add", listOf(RawValue.I32(2), RawValue.I32(3))).getOrThrow()
    check(values == listOf(RawValue.I32(5)))
} finally {
    session.close()
    module.close()
}
```

Native Raw Export uses a matching `.cwasm` or `.pwasm` descriptor instead of
`RAW_WASM`. The session API, scalar values, imports, and checked memory API are
the same.

## Handle Results and Errors

Use `callResult()`, `invokeRawResult()`, `invokeComponentResult()`, or the Core
session result APIs when a failure must be handled as data. Each result is
`Success(value)` or `Failure(failure)`. Branch on `failure.code`, not the text
of `failure.message`.

For example, an action without a bound handler returns `ACTION_NOT_BOUND`.
`throwOnFailure()` converts a failure into `WasmlineException` only when the
caller explicitly requests exceptions. See [FAQ](/en/docs/faq) for the Core
response-frame fields and artifact rules.
