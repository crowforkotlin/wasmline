# 编译器插件

## IR 变换流水线

`wasmline-kotlin-plugin` 运行在 **Kotlin IR 编译阶段**，不使用 KSP，也不生成源码文件。最后的 export 或初始化 hook 由所选 guest transport 决定。

| 步骤 | 类 | 操作 |
|---|---|---|
| 1 — 发现 | `WasmlineIrGenerationExtension` | 遍历所有 `IrDeclarationContainer` 节点；收集在超类型层级中包含 `WasmlineService` 的 `IrClass` 声明 |
| 2 — 校验 | `WasmlineServiceContractValidator` | 校验每个契约，并对不支持的声明报告编译器错误 |
| 3 — 桥接生成 | `WasmlineBridgeGenerator` | 为每个通过验证的契约生成一个 `internal class {Contract}_WasmlineBridge : WasmlineGeneratedBridge`，并将该类直接注入父级 `IrFile` |
| 4 — 调用点重写 | `WasmlineTypedEntryPointRewriter` | 定位所有 `link<T>()`、`bind(contract, impl)` 与 `bind(impl)` 调用点，并将其替换为直接实例化桥接类的表达式 |
| 5 — Guest transport hook | `WasmlineWasiEntryExportGenerator` 或 `WasmlineComponentServiceInitGenerator` | 根据编译器选项生成 Core WASI exports，或连接 Component Service 初始化 hook |

## 静态契约约束

以下约束在编译期强制执行。任何违反都会被报告为**编译器错误**，并阻止 IR 成功生成：

| 约束 | 要求 |
|---|---|
| 声明种类 | 契约必须是直接或间接继承 `WasmlineService` 的 `interface` |
| 属性 | 不支持服务属性，应改用函数 |
| 成员可见性 | 所有函数都必须声明为 `public` |
| suspend 能力 | 任何契约函数都不允许使用 `suspend` 修饰符 |
| 泛型类型参数 | 契约及其函数均不允许使用泛型类型参数 |
| 方法名唯一性 | 单个契约内不支持同名重载方法 |
| `vararg` 参数 | 不允许 |
| 默认参数值 | 不允许 |
| 扩展接收者 | 不支持把扩展函数或扩展属性声明为契约成员 |
| 服务类型值 | 参数或返回值不能使用服务契约类型 |

函数可以包含多个普通参数。生成的 bridge 会为完整参数列表创建 serializer 数组和参数 descriptor。

## Action 标识符

每个服务方法使用以下 action 字符串：

```text
com.example.EchoService#echo
```

生成的调用端、binder 与 dispatcher 使用同一个值。由于不允许方法重载，契约名与方法名足以唯一标识方法。修改契约包名、契约名或方法名会改变 action；修改参数类型不会改变 action，但会改变序列化 payload 契约，因此仍属于兼容性变更。

## IR Box 测试工作流

Box 测试夹具位于 `wasmline-kotlin-plugin/testData/box/`。每个夹具都是一个包含 `fun box(): String` 入口点的源码文件，并在成功执行时返回 `"OK"`：

```bash
cd wasmline-multiplatform

# 1. 在 testData/box/{name}.kt 中编写或修改夹具
# 2. 重新生成测试运行器
./gradlew :wasmline-kotlin-plugin:generateTests

# 3. 执行 — 首次运行会生成 FIR 与 IR 快照
./gradlew :wasmline-kotlin-plugin:test \
  --tests 'crow.wasmline.kotlin.runners.JvmBoxTestGenerated'

# 4. 提交前检查生成的 *.fir.txt 与 *.fir.ir.txt
```

<Callout type="warn" title="自动生成的构建产物">
  以下文件属于**自动生成的构建产物**，绝不能手动编辑：`test-gen/**`、`testData/box/*.fir.txt` 与 `testData/box/*.fir.ir.txt`。手工修改会在下一次生成和测试流程中被覆盖或拒绝。
</Callout>

## 相关 Gradle 任务

```bash
cd wasmline-multiplatform

# 重新生成测试运行器
./gradlew :wasmline-kotlin-plugin:generateTests

# box 测试
./gradlew :wasmline-kotlin-plugin:test \
  --tests 'crow.wasmline.kotlin.runners.JvmBoxTestGenerated'
```

仓库保留了 `AbstractJvmDiagnosticTest` 框架，但生成器中的 diagnostics model 尚未启用。当前没有 `testData/diagnostics/` 目录或 `JvmDiagnosticsTestGenerated` runner。
