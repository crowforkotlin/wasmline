- 所有核心组件（Engine, Module）均通过私有构造函数配合静态 `getInstance()` 方法实现单例，并显式删除拷贝构造与赋值运算符。
- 涉及共享状态变更的方法（如 `load`, `invokeInbound`）均在入口处获取互斥锁，并在执行耗时操作（如文件 IO 或 Wasm 编译）前主动释放锁以减少 contention。
- Host 函数回调统一采用静态成员函数配合 `wasmtime_caller_context` 提取 `Session` 实例指针的方式，实现 C 风格回调与 C++ 对象状态的桥接。
- 关键资源（如 `wasm_config_t`, `wasmtime_error_t`）的管理遵循 RAII 原则或在错误分支中立即执行对应的 `_delete` 清理逻辑，防止内存泄漏。
