- 在 iOS 桥接代码中，所有涉及 C 指针返回值的操作均遵循“读取后立即释放”原则，显式调用 `wasmline_free_memory` 防止内存泄漏。
- JNI 实现中严格遵循资源获取即初始化 (RAII) 或手动配对释放模式，确保 `GetStringUTFChars` 与 `ReleaseStringUTFChars`、`GetByteArrayElements` 与 `ReleaseByteArrayElements` 成对出现。
- 平台特定的引导逻辑（Bootstrap）均封装在私有的 `ensureBootstrapped` 或 `iosBootstrap` 函数中，并在公开 API 调用前执行，确保原生库仅加载一次。
