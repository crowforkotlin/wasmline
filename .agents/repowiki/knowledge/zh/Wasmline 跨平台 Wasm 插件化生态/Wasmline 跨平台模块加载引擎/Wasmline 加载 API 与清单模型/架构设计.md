- 公共 API 层：`WasmlineSource`（密封接口）抽象本地构件、本地产清单、远程清单三种来源；`WasmlineLoadRequest` 聚合来源、配置、元数据与可插拔解析器。
- 解析扩展点：`WasmlineSourceResolvers` 提供 `WasmlineLocalPackageResolver` 与 `WasmlineRemotePackageResolver` 函数式接口，返回 `WasmlineSourceResolution`（继续或完成），实现链式解析与终止。
- 数据模型层：`model/Manifest.kt` 定义 Protobuf 序列化的 `SignedManifestEnvelope`（含签名、算法、公钥 ID）与 `WasmlineManifest`/`WasmlineArtifact`，明确构件类型（WASM/CWASM/PWASM）与校验信息。
- 内部支撑：`internal/` 提供常量（如 `manifest.wlm`）、主机目标抽象（`WasmlineHostArtifactTarget`）与密码学抽象（`SignatureAlgorithm`、`SignatureAlgorithmId`），通过 expect/actual 机制适配平台差异，保持 commonMain 的平台无关性。
