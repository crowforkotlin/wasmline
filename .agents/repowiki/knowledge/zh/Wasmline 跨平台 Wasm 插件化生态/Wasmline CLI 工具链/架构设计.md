- **入口与路由**：`Main.kt` 基于 `Clikt` 框架注册子命令（Build, Compile, Manifest, Download, GenerateKeyPair）。
- **核心流程**：`Compile.kt` 调用 `wasmtime-min` 进行多架构 AOT 编译并生成中间态 `compile-result.json`；`Manifest.kt` 读取该结果并使用 Ed25519 算法对 Protobuf 格式的清单进行签名；`Build.kt` 编排从编译到打包 ZIP 的全链路。
- **依赖管理**：通过 `build.gradle.kts` 引入 `ktor-client` 处理 GitHub Release 下载，利用 `kotlinx.serialization` 处理 JSON/Protobuf 序列化。
- **数据模型**：定义 `CompileResult` 作为编译阶段与清单生成阶段的契约模型。
