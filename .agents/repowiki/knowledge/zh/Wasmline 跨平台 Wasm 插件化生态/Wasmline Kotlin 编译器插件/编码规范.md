- 内部 API 统一使用 `internal` 可见性修饰符，包括扩展函数、工具类与生成辅助方法，避免插件实现细节泄露到外部。
- IR 构建时广泛采用 `@OptIn(UnsafeDuringIrConstructionAPI::class)` 与 `irFunctionBody`/`DeclarationIrBuilder` 组合，在持有符号上下文中直接操作 IR 节点偏移与语句块。
- 命名约定上，生成的桥接类遵循 `<ContractName>_WasmlineBridge` 模式，WASI 导出函数使用双下划线前缀常量（如 `__wasmline_wasi_init`）以避免与用户代码冲突。
- 诊断报告统一通过 `report`/`reportError` 辅助函数，传入 `MessageCollector`、`IrFile` 与 `IrDeclaration`，由工具自动从 `fileEntry.getSourceRangeInfo` 提取源码位置信息。
