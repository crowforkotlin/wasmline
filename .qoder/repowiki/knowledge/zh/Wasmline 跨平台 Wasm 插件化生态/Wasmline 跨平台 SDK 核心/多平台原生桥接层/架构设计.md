- **分层架构**：采用 Kotlin 平台特定源集（`iosMain`, `jniMain`）作为入口，通过 C/C++ 中间层（Bridge）调用底层 C++ API (`wasmline::Api`)。
- **iOS 实现**：利用 Kotlin/Native 的 `cinterop` 机制（`wasmline.def`）直接绑定 C 头文件 (`WasmlineNative.h`)，在 Kotlin 侧通过 `memScoped` 管理内存并处理 C 指针交互。
- **Android 实现**：基于 JNI 标准规范，在 C++ 侧实现 `Java_crow_wasmline_Wasmline_*` 导出函数，负责 Java/Kotlin 对象与 C++ 数据结构（如 `jbyteArray` 到 `std::string`）的转换。
- **依赖方向**：Kotlin 平台代码 -> 原生桥接头文件/导出符号 -> 核心 C++ 运行时 (`Api.cpp`)。
