- **分层架构**：采用 `Api`（外观层）-> `Engine/Module/Session`（核心逻辑层）-> `wasmtime.h`（底层 C API）的三层结构。
- **单例管理**：`Engine` 和 `Module` 均采用单例模式，分别全局管理 Wasmtime 引擎实例和编译后的模块缓存。
- **会话模型**：`Session` 封装了 Store、Context 和 Linker，负责 WASI 环境配置及 Host 函数注册，支持通过 `OutboundHandler` 接口实现 Wasm 到宿主的双向调用。
- **并发控制**：`Module` 内部使用 `std::mutex` 配合 `std::condition_variable` 实现线程安全的懒加载与去重；`Api` 使用 `std::shared_mutex` 优化多读少写的会话缓存访问。
- **扩展机制**：通过 `extensions/Concurrency.h` 提供 RAII 风格的并发守卫，确保在异常或错误路径下也能正确释放锁并通知等待线程。
